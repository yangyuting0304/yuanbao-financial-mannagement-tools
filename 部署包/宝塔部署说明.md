# 元宝爱财 - 宝塔面板部署说明（阿里云 ECS）

> 适用：宝塔面板 + Nginx，访问地址为 `http://120.24.240.129/yuanbao/`

## 一、文件清单

上传到宝塔目录 `/www/wwwroot/120.24.240.129/yuanbao/`：

| 文件 | 作用 |
|------|------|
| `index.html` | 前端页面 |
| `server.js` | 数据代理服务（详情页/K线/资金流全靠它） |
| `start.sh` | 临时启动脚本（宝塔终端里运行，关闭终端后进程会停） |
| `run.sh` | 前台运行脚本（给 Supervisor 用，常驻后台） |
| `supervisor-yuanbao.ini` | 宝塔进程守护管理器配置文件 |

## 二、关键：为什么之前不行？

你已经在宝塔上传了 `index.html`，所以手机能打开页面。**但详情页的数据需要 `server.js` 运行起来才行。**

之前 `./start.sh` 启动后，**宝塔终端窗口一关，进程就被杀了**，所以 `server.js` 没有常驻运行。

## 三、正确部署步骤

### 步骤 1：上传文件

宝塔 → 文件 → 进入 `/www/wwwroot/120.24.240.129/yuanbao/`

把 zip 里的 5 个文件全部放进去（覆盖旧的 `index.html`）。

### 步骤 2：配置宝塔进程守护管理器（Supervisor）

宝塔 → 软件商店 → 搜索安装 **"进程守护管理器"**（英文名 Supervisor）。

安装完成后：

1. 宝塔 → 安全 → 先放行 **18765** 端口（入方向 TCP，授权对象 `0.0.0.0/0`）。
2. 把 `supervisor-yuanbao.ini` 上传到宝塔的 Supervisor 配置目录：
   ```
   /www/server/panel/vhost/supervisor/supervisor-yuanbao.ini
   ```
3. 编辑这个 ini 文件，把 `environment=JIN10_TOKEN="你的金十token"` 里的 `"你的金十token"` 换成你自己的金十 key。如果没有，可以先删掉这一行，会用 server.js 内置的 key（公网环境不推荐）。
4. 宝塔 → 进程守护管理器 → 重载配置 → 启动 `yuanbao`。

启动成功后，服务器本地的 `127.0.0.1:18765` 就在运行了。

### 步骤 3：配置 Nginx 反向代理

宝塔 → 网站 → 找到 `120.24.240.129` → 设置 → 反向代理 → 添加：

| 配置项 | 值 |
|--------|-----|
| 代理名称 | `yuanbao` |
| 目标 URL | `http://127.0.0.1:18765` |
| 代理目录 | `/yuanbao/` |
| 发送域名 | `120.24.240.129` |

保存后，点「重载配置」。

### 步骤 4：验证

宝塔 → 终端，执行：

```bash
curl -s "http://120.24.240.129/yuanbao/api/detail?secid=0.002384" | head -c 120
```

如果返回 JSON 数据（不是 404 HTML），就成功了。

然后手机访问 `http://120.24.240.129/yuanbao/`，点股票详情即可看到分时/日K/周K/月K。

## 四、常见问题

### 1. 手机仍然 404

检查 Supervisor 里 `yuanbao` 进程是否为「运行中」：
- 如果显示停止，看日志 `/www/wwwroot/120.24.240.129/yuanbao/server.err.log`。
- 常见原因：Node.js 没装。在宝塔终端执行 `node -v`，如果没有，去软件商店安装 Node.js 版本管理器。

### 2. 只有首页，详情页空白

说明 `index.html` 上传成功但 `server.js` 没启动，或者 Nginx 反代没配。按上面步骤检查。

### 3. 宝塔没有进程守护管理器

如果没有 Supervisor，可以用 `screen` 临时常驻（需要安装 screen）：

```bash
yum install -y screen    # CentOS
apt-get install -y screen # Ubuntu/Debian
screen -S yuanbao -dm bash -c "cd /www/wwwroot/120.24.240.129/yuanbao && ./start.sh"
```

但不推荐，服务器重启后不会自动启动。

## 五、安全提醒

- 金十 token 建议通过 Supervisor 配置文件的 `environment=` 传入，不要依赖 `server.js` 硬编码。
- 公网暴露后，尽量不要把 `server.js` 里的硬编码 token 提交到公开仓库。
